# mamelonanosy

Static public build of the Delivery Manager web UI.

Use this folder as the site root for GitHub Pages, Cloudflare Pages, Netlify, or any other static host.

Notes:

- `index.html` automatically uses the local Python API on `localhost`.
- On a public/static URL, it uses the existing Firebase Realtime Database from `order-form.html`.
- PDF exports, undo, and redo still require the desktop Python server because those features are generated by `delivery.py`.
- Confirmed daily route plans can be viewed from the hosted page. Route generation and assignment confirmation remain on the desktop Python server so the Google Geocoding key is never exposed publicly.
